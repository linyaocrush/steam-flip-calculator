# Steam 倒余额计算器

一个用于计算 Steam 市场倒余额收益的工具，帮助用户快速计算在第三方平台购买物品后在 Steam 市场出售的利润。

## 功能特点

- 📊 **倒余额计算**：输入成本和售价，自动计算实际到手余额、折扣比例
- 🔄 **反推挂刀价**：根据成本反推保本所需的最低售卖价格
- 📝 **交易记录**：记录每笔交易，便于追踪历史
- 📈 **统计汇总**：查看整体交易统计和折扣汇总
- 🌙 **明暗主题**：支持明暗主题切换

## 使用说明

### 计算器页面

1. **物品名称**：输入物品名称（如 CS2 刀/皮肤）
2. **备注**：可选，添加额外说明
3. **第三方成本（单价）**：在第三方平台购买的单价
4. **Steam 售出金额（单价）**：计划在 Steam 市场出售的单价
5. **数量**：购买的数量

**计算结果说明：**
- **Steam 实际到账(单价)**：扣除 15% 手续费后的实际到手金额
- **总花费**：购买物品的总成本
- **总到手余额**：全部卖出后的实际到手余额
- **倒余额比例**：成本 / 到手余额（越低越好）
- **折扣**：1 - 倒余额比例（越高越好）
- **保本售卖价**：为了保本所需的最低售卖价格

### 历史页面

- 查看所有交易记录
- 支持删除单条记录
- 支持清空全部历史

### 统计页面

- 总数量：交易物品总数
- 总花费：累计花费金额
- Steam 售出总额：累计售出金额（未扣手续费）
- 总到手余额：累计实际到手金额（已扣手续费）
- 整体倒余额比例：总花费 / 总到手余额
- 整体折扣：基于所有交易的平均折扣

## API 接口

### 计算接口

**POST** `/api/calculate`

请求体：
```json
{
    "unit_cost": 70,
    "unit_steam_sell": 100,
    "qty": 1
}
```

响应：
```json
{
    "unit_net": 85.0,
    "total_cost": 70.0,
    "total_net": 85.0,
    "total_steam_sell": 100.0,
    "ratio": 0.8235,
    "discount": 0.1765,
    "need_sell": 82.35
}
```

### 记录接口

**GET** `/api/records` - 获取所有记录

**POST** `/api/records` - 添加记录

**DELETE** `/api/records/{id}` - 删除单条记录

**DELETE** `/api/records` - 清空所有记录

### 统计接口

**GET** `/api/stats` - 获取统计数据

## 计算原理

### Steam 手续费规则
Steam 市场固定收取 15% 的手续费：
- 卖出 100 元，实际到账 85 元
- 到手余额 = 售出价格 × 0.85

### 保本价格计算
为了确保不亏本，需要：
```
保本售卖价 = 第三方成本 / 0.85
```

示例：成本 70 元，保本价 = 70 / 0.85 ≈ 82.35 元

## 注意事项

1. 确保后端服务先启动，前端才能正常连接
2. 数据库文件 `steam_flip.db` 会自动创建
