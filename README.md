# Steam 倒余额计算器

一个用于计算 Steam 市场倒余额收益的工具，帮助用户快速计算在第三方平台购买物品后在 Steam 市场出售的利润。

## 🎉 更新公告

项目已从 **Flask** 迁移到 **FastAPI**，提供更好的性能和开发体验！

## 功能特点

- 📊 **倒余额计算**：输入成本和售价，自动计算实际到手余额、折扣比例
- 🔄 **反推挂刀价**：根据成本反推保本所需的最低售卖价格
- 🎯 **目标金额反推**：输入目标到手金额，自动计算需要购买的物品数量
- 💰 **多货币支持**：支持买入货币、售出货币、我的货币三种货币设置
- 💱 **汇率自动转换**：自动获取汇率，统计金额自动转换为我的货币
- 📝 **交易记录**：记录每笔交易，便于追踪历史，支持不同货币显示
- 📈 **统计汇总**：查看整体交易统计和折扣汇总，金额自动转换为我的货币
- 🌙 **明暗主题**：支持明暗主题切换
- 🌍 **多语言**：支持中文、英文、日文

## 使用说明

### 计算器页面

1. **物品名称**：输入物品名称（如 CS2 刀/皮肤）
2. **备注**：可选，添加额外说明
3. **第三方成本（单价）**：在第三方平台购买的单价
4. **Steam 售出金额（单价）**：计划在 Steam 市场出售的单价
5. **数量**：购买的数量
6. **目标到手金额**：输入目标到手金额，自动计算需要购买的物品数量

**计算结果说明：**
- **Steam 实际到账(单价)**：扣除手续费后的实际到手金额
- **总花费**：购买物品的总成本（买入货币）
- **总到手余额**：全部卖出后的实际到手余额（售出货币）
- **倒余额比例**：成本 / 到手余额（越低越好）
- **折扣**：1 - 倒余额比例（越高越好）
- **保本售卖价**：为了保本所需的最低售卖价格
- **所需数量**：达到目标到手金额需要购买的物品数量
- **所需成本**：达到目标到手金额需要的总成本

### 历史页面

- 查看所有交易记录
- 支持删除单条记录
- 支持清空全部历史

### 统计页面

- 总数量：交易物品总数
- 总花费：累计花费金额
- Steam 售出总额：累计售出金额（未扣手续费）
- 总到手余额：累计实际到手金额（已扣手续费）
- 整体倒余额比例：总花费 / 总到手余额
- 整体折扣：基于所有交易的平均折扣

### 设置页面

- **买入货币**：第三方平台使用的货币（如 CNY）
- **卖出货币**：Steam 市场所在区域的货币（如 USD）
- **我的货币**：用于统计显示的货币，金额会自动转换
- **汇率**：自动获取（CNY→USD），12小时缓存
- **Steam 手续费率**：可自定义（默认 15%）
- **主题模式**：浅色/深色模式
- **语言**：中文/英文/日文

### 多货币说明

本工具支持三种货币设置，确保计算准确：

| 货币类型 | 用途 | 示例 |
|----------|------|------|
| 买入货币 | 第三方平台购买物品的货币 | CNY（人民币） |
| 售出货币 | Steam 市场收款的货币 | USD（美元） |
| 我的货币 | 统计显示使用的货币 | CNY（人民币） |

**汇率转换逻辑：**
- 历史记录：成本显示买入货币，到手金额显示售出货币
- 统计界面：所有金额自动转换为我的货币显示
- 折扣计算：基于转换后的金额计算，确保准确性

### 计算接口示例

**POST** `/api/calculate`

请求体：
```json
{
    "unit_cost": 70,
    "unit_steam_sell": 100,
    "qty": 1,
    "use_exchange": false,
    "exchange_rate": 1.0,
    "fee_rate": 0.15
}
```

响应：
```json
{
    "unit_net": 85.0,
    "total_cost": 70.0,
    "total_net": 85.0,
    "total_steam_sell": 100.0,
    "ratio": 0.8235,
    "discount": 0.1765,
    "need_sell": 82.35
}
```

## 计算原理

### Steam 手续费规则
Steam 市场收取交易手续费（默认 15%）：
- 卖出 100 元，实际到账 85 元
- 到手余额 = 售出价格 × (1 - 手续费率)

### 保本价格计算
为了确保不亏本，需要：
```
保本售卖价 = 第三方成本 / (1 - 手续费率)
```

示例：成本 70 元，手续费率 15%，保本价 = 70 / 0.85 ≈ 82.35 元

## 迁移说明

| 方面 | Flask | FastAPI |
|------|-------|---------|
